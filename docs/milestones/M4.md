# M4: print-ready output and public viewer

Goal: a laid-out book becomes a complete, orderable print package (interior PDF, cover PDF sized
for the chosen Lulu product, resolution and geometry preflight) and can be shared through a public
token link that shows the book as spreads without exposing Immich.

Read `CLAUDE.md` first. Everything under "Existing seams" already works; build on it, do not
re-implement it.

## Existing seams

- Render pipeline: `apps/server/src/render/service.ts` (`RenderService`: `renders` table, serial
  queue, `create(book, kind)`, `idle()`, `filePath(id)`), `renderer.ts` (`ChromiumRenderer.render`
  builds static HTML with `renderPrintDocument` from `packages/pages/src/print.tsx`, intercepts
  `https://render.bookbinder.local/img/...`, renders batches of 12 pages, merges with `pdf-lib`,
  checks page count and size, returns `warnings`), `images.ts` (`ImageStore.slotImage(asset, kind,
  wPx, hPx, crop)`, `RENDER_PPI = { proof: 110, print: 300 }`, `JPEG_QUALITY`).
- `RenderKind` is `z.enum(['proof', 'print'])` in `packages/shared/src/book.ts`; `RenderJob`,
  `CreateRenderInput` next to it. Routes in `apps/server/src/routes/books.ts` under
  `/api/books/:id/renders`. Web: `apps/web/src/components/Renders.tsx` (`RenderButtons`, `RenderList`).
- Formats: `packages/shared/src/format.ts` (`FORMAT_PRESETS`, `bleedIn`, `safetyIn`,
  `gutterSafetyIn`, `minPages/maxPages/pageMultiple`, `LuluProduct`, `luluPodPackageId`).
  `Book.luluProduct` already exists with defaults.
- Cover template: `cover-editorial` in `packages/layout/src/templates.ts` (`kind: 'cover'`,
  back = x in [-1, 0], front = x in [0, 1] in trim-width units, slots `p1` hero, `title`, `rule`,
  `subtitle`, `back-blurb`, `spine`). Nothing renders it yet. `TemplateSchema` is in
  `packages/shared/src/template.ts`.
- Resolution: `effectivePpi(width, height, wIn, hIn)` (used by `apps/web/src/pages/Editor.tsx`,
  `ppiTone`: amber < 200, red < 150). `PageView` has a slot-decoration hook for badges.
- Spreads: `toSpreads`, `spreadIndexOfPage`, `spreadLabel` in `packages/pages/src/spreads.ts`.
  `bookMetaFor` in `packages/pages/src/meta.ts` computes title, dates and chapter text.
- Public surface: `apps/server/src/routes/public.ts` answers 404 for `/s/*` and `/public/*`;
  `routes/static.ts` deliberately does not SPA-fallback those prefixes. `SettingKeys.publicUrl`
  and `PUT /api/settings/public-url` already store the external base URL (`config.PUBLIC_URL` is
  the env fallback).
- Templates `colophon` and `qr` exist (back matter). `NO_FOLIO_TEMPLATE_IDS` in
  `packages/layout/src/paginate.ts` is the folio rule.
- Tests: `apps/server/src/books/layout.test.ts` renders proof and print PDFs against the fake
  Immich and parses them with `pdf-lib`; copy its shape.

## Deliverables

### 1. Cover model and cover PDF

- Add `BookCover` to `packages/shared/src/book.ts`: `{ templateId: 'cover-editorial', slots:
  SlotContent[], spineText?: string, blurb?: string }`; `Book.cover` optional. Default cover is
  created by `layoutBook` when absent: hero = highest composite picked photo (face crop applied),
  title = book title, subtitle = `bookMetaFor` date range, spine text = title.
- Add `coverGeometry(format, product, pageCount, override?)` in `packages/layout/src/cover.ts`
  returning `{ widthIn, heightIn, spineIn, wrapIn, frontLeftIn, source: 'estimate' | 'lulu' }`.
  Without an override the spine is an ESTIMATE: `pageCount * caliper + boardIn`, caliper
  `080CW444` 0.002252 in, `060UW444`/`060UC444` 0.0025 in, `boardIn` 0.25 for casewrap (`CW`)
  and 0 for perfect-bound (`PB`), wrap 0.75 in for casewrap and `bleedIn` otherwise. Mark the
  numbers `// ESTIMATE, verified against Lulu /cover-dimensions/ in M5` in code and in
  `docs/print-specs.md`. M5 passes Lulu's real dimensions as `override`.
- Extend `renderPrintDocument` (`packages/pages/src/print.tsx`) with a cover sheet: one
  `.bb-sheet` of `widthIn x heightIn`, template x coordinates mapped so back cover occupies
  `[wrap, wrap + trimW]`, spine `[wrap + trimW, wrap + trimW + spine]`, front the rest; the
  `spine` slot is re-laid to the actual spine width, text rotated 90 degrees reading
  bottom-to-top, hidden when `spineIn < 0.25`. Home presets (`vendor: 'generic'`) get no cover
  render (render returns 409 with a clear message).
- `RenderKind` gains `'cover'`. `RenderService.create(book, 'cover')` renders one page at
  300 ppi from originals; the post-pass checks one page at the expected size. Store the
  geometry used in `renders.data` (new nullable JSON column) so preflight can tell a stale cover.

### 2. Page previews (PNG)

- `RenderKind` gains `'preview'`: in the same Chromium document as a proof render, screenshot
  each `.bb-sheet` (`locator.screenshot`, `deviceScaleFactor` chosen so the longest edge is
  1600 px), write `DATA_DIR/exports/<renderId>/NNNN.png` (four-digit page index) and, when a cover
  exists, `cover.png`. `renders.filePath` points at the directory; `pageCount` is set; file size
  is the directory total.
- Route `GET /api/books/:id/renders/:rid/pages/:n.png` for the admin UI (BookDetail shows the
  first spread as a thumbnail strip). The public viewer reads the same files through `/s/:token`.

### 3. Preflight

- `GET /api/books/:id/preflight` -> `Preflight` schema (`packages/shared/src/api.ts`):
  `{ ok: boolean, items: PreflightItem[] }`, item `{ level: 'error' | 'warn', code, message,
  pageIndex?, slotId? }`. Checks, in this order:
  - `page-count`: outside `minPages..maxPages` or not a `pageMultiple` -> error.
  - `empty-slot`: a photo slot with no asset -> warn.
  - `low-resolution`: effective ppi < 150 error, < 200 warn (reuse `effectivePpi`).
  - `caption-safety`: caption text slot whose box crosses the safety band -> warn (compute from
    the template geometry, `format.safetyIn`, `gutterSafetyIn`).
  - `cover-missing` (Lulu formats) -> error; `cover-stale` when the cover render's stored page
    count differs from `book.pages.length` -> warn.
  - `render-missing`: no done `print` render newer than `book.updatedAt` -> warn.
- Pure logic in `packages/layout/src/preflight.ts` (unit-tested with a fixture book); the route
  just gathers assets and render rows.
- BookDetail gets a "Print readiness" card listing items with links into the editor
  (`/books/:id/edit?page=N`); `Editor.tsx` does not read a query parameter yet, add that (open on the
  spread containing page N).

### 4. Public viewer

- Table `shares` (migration): `id`, `book_id` (cascade), `token` (unique, 32 bytes base64url),
  `password_hash` (argon2, nullable), `expires_at` (nullable ISO), `allow_download` (bool),
  `revoked_at` (nullable), `created_at`, `last_viewed_at`, `views` (int).
- Admin routes (`/api/books/:id/shares`): list, create (`{ expiresInDays?, password?,
  allowDownload }` -> full URL built from `publicUrl` setting, else `config.PUBLIC_URL`, else the
  request origin with a warning), update, revoke (`DELETE`). Schemas `ShareView`,
  `CreateShareInput` in `packages/shared/src/api.ts`.
- Public routes replace the stub in `routes/public.ts`; all rate-limited (`@fastify/rate-limit`
  is already registered for login, reuse it at 60/min per IP):
  - `GET /s/:token` -> serves `index.html` from `WEB_DIST` (the SPA renders the viewer); 404 JSON
    when `WEB_DIST` is absent.
  - `GET /s/:token/book.json` -> `ViewerBook`: `{ title, subtitle?, dates?, chapters:
    [{ title, subtitle?, startsAtPage }], pageCount, cover: boolean, download: boolean,
    format: { trimWidthIn, trimHeightIn } }`. No asset ids, no Immich data.
  - `GET /s/:token/pages/:n.png`, `GET /s/:token/cover.png` from the newest done `preview` render.
  - `GET /s/:token/pdf` when `allow_download`: newest done `print` render, else `proof`, else 404.
  - `POST /s/:token/unlock` `{ password }` -> sets a signed cookie `bb_share_<token>` (24 h);
    protected routes answer 401 `{ needsPassword: true }` without it.
  - Expired or revoked tokens answer 410 with `{ reason: 'expired' | 'revoked' }`.
- Web: `apps/web/src/pages/Viewer.tsx` at route `/s/:token` outside `Shell` and `RequireAuth`
  (add to `App.tsx`). Dark backdrop, cover first (when present), then spreads (`toSpreads`
  logic on page indexes), left/right keys and swipe, chapter list drawer, page counter, download
  button, password form, expired/revoked states, single-page mode under 720 px. Lazy-load PNGs
  two spreads ahead. Set `<title>` to the book title.
- BookDetail: "Share" card with create dialog (expiry, password, download toggle), copyable
  link, "Preview out of date, re-render" hint when the newest preview render predates
  `book.updatedAt`, revoke.

## Judgement calls already made

- The viewer shows rendered page PNGs, not live React pages. This keeps Immich completely out of
  the public surface and means the viewer needs no asset proxy. Cost: a share needs a preview
  render, which the Share dialog queues automatically when none is current.
- Spine width is estimated in M4 and replaced by Lulu's `/cover-dimensions/` in M5. The PDF
  records which source was used.
- Password protection uses argon2 (already a dependency) and a per-share cookie; no sessions table.
- No QR code on the colophon yet (would need a new dependency); listed under M7 unless it turns
  out trivial with a pure-TS encoder.
- Cover editing stays minimal in M4: BookDetail lets the user pick the cover photo from the
  book's placed photos, and edit title/subtitle/spine/blurb text. Free placement is M6.

## Out of scope

Lulu API calls, public export URLs for Lulu (`/public/exports/*`), order tracking (all M5);
free-form cover design (M6); AI captions, map pages, QR (M7).

## Acceptance criteria

1. `POST /api/books/:id/renders { kind: 'cover' }` on a Lulu-format book with pages produces a
   one-page PDF whose size equals `coverGeometry` width x height in points; a `home-*` book gets 409.
2. `{ kind: 'preview' }` writes one PNG per page (plus `cover.png` when a cover exists) and the
   admin page route serves them.
3. `GET /api/books/:id/preflight` reports `page-count`, `low-resolution`, `cover-missing` and
   `cover-stale` correctly on fixture books (unit tests on the pure function, one route test).
4. Creating a share returns an absolute URL; `GET /s/:token/book.json` contains no asset ids and
   no Immich URLs; pages and PDF are served; wrong password gives 401, correct password sets the
   cookie; expiry and revoke give 410; rate limiting applies.
5. The SPA viewer renders spreads from the fake-Immich book, navigates with keys, shows chapters,
   and downloads the PDF when allowed (manual check, screenshot in the final message).
6. `corepack pnpm check` green; new tests cover 1 to 4; existing tests untouched.

## Verification

```sh
corepack pnpm check
corepack pnpm --filter @bookbinder/server exec vitest run src/books src/routes src/render
```

Manual flow (see `CLAUDE.md` for ports): build web, start `server` and `fake-immich`, connect,

preflight card, create a share with a password, open `/s/<token>` in the browser pane, unlock,
page through, download. Report anything deferred explicitly.

## Delivered

Landed 2026-09-14. Everything in the deliverables list shipped; deviations from the plan:

- Preview PNGs live at `DATA_DIR/exports/<book id>/<render id>/NNNN.png` (per-book folder like the
  PDFs, so deleting a book removes everything) rather than `exports/<render id>/`.
- `cover-missing` has two levels: error when the book has no cover document, warn when it has one
  but no cover PDF yet (parallel to `render-missing`). `cover-stale` also fires when the book changed
  after the cover render, not only on a page-count change.
- `RenderService` marks a book `rendered` through a new `BookStore.setStatus` that does not bump
  `updatedAt`; otherwise every print render made itself "older than the book" in preflight.
- `ViewerBook` carries `format.bleedIn` and `coverFront` (fractions of `cover.png`) so the viewer can
  crop the bleed off pages and show the front cover alone, like a page. Still no asset ids or Immich data.
- The unlock cookie value is `<share id>.<expiry>.<hash of the password hash>`, signed; changing or
  removing the password invalidates every viewer's cookie. Unlock is limited to 10 attempts/min per IP.
- The `hero-strip` caption moved up 16 px (from 4 px to 20 px above the safety line) so it no longer
  sits inside the safety band; every other caption already stopped at the line.
- The cover template's hero is stretched to the sheet edge (over the whole wrap), not just to the
  interior bleed, so hardcovers get a full wrap-around photo.
- Cover text uses the theme's paper colour with a shadow over a bottom scrim when a photo is present.
- `Editor.tsx` reads `?page=N` (0-based, wins over `?spread=`) and clears it on navigation.
- No cover for `home-*` formats anywhere: the layout does not create one, preflight skips the checks,
  the render route answers 409, the Cover PDF button is hidden.

Deferred: QR code on the colophon (M7), Lulu cover dimensions (M5, `coverGeometry` already takes the
override), free cover placement (M6), a viewer for books without a preview render (it shows a
"not published yet" note instead; since M7 a share queues the preview and the viewer polls).
