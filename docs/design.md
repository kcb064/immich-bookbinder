# Design decisions

Design canvases (Claude Design, September 2026):

- App UI: https://claude.ai/code/artifact/e8dfd26e-db6d-4e3f-909b-e51dc6739dc3
- Book templates: https://claude.ai/code/artifact/7847f459-736f-45be-a2b4-55e1cc246f44

Working files live in `design/` and are generated by `design/gen.mjs`. Edit the generator, not the `.dc.html` output.

## Decisions (2026-09-11)

| Topic | Decision |
|---|---|
| Book style | **Warm editorial**: off-white paper `#f6f1e8`, ink `#2a2622`, captions `#6b625a`, accent `#b5563a`. Display face Newsreader italic, body Source Serif 4. Titles 72–96 px italic, captions 14 px serif (~10.5 pt printed). Margins 56 px outer, 16 px between photos. Clean-gallery sketches kept as a possible second theme. |
| Trip suggestions | Only inside the New book wizard, not on the dashboard. |
| Spine text | As drawn (reads bottom to top). |
| Panoramas across the gutter | Stay available as a template option, with a warning about the ~0.75 in lost in a casewrap. |
| App chrome | Dark, utilitarian, Immich-adjacent. Background `#0f1115`, surfaces `#171a21` / `#1e222b`, border `#2a2f3a`, text `#e8eaf0`, muted `#8d95a7`, accent `#7c8cff` / `#5563e8`. Instrument Sans for UI, JetBrains Mono for numbers. Controls 44 px tall. |

## Page geometry (8.5 × 8.5 in default)

| Measure | Value |
|---|---|
| Trim | 8.5 × 8.5 in (816 px at 96 ppi) |
| Bleed | 0.125 in each side; PDF page 8.75 × 8.75 in |
| Safety | 0.5 in from trim |
| Gutter safety | 0.375 in from spine |
| Cover | one spread, size from Lulu `/cover-dimensions/` |
