## Designer conventions (M6)

The editor is a designer on the same page model: templates are starting points, and any slot can be
placed by hand without a second data model.

| Topic | Convention |
|---|---|
| Units | Frames are in template units: fractions of the trim width (`x`, `w`) and trim height (`y`, `h`), origin at the trim's top-left, negative values reach into the bleed. The cover keeps back = `[-1, 0]`, front = `[0, 1]` with the spine inserted at 0, so a cover design survives a change of page count. The panel shows inches; frames round to 1/10000. |
| Custom pages | Any hand placement (a `frame` on a template slot, an added photo or text box) marks the page `custom`. Custom pages keep their template as the base, are skipped by "Re-lay out" (their photos stay on them, the page returns to its index, chapter openers are re-aligned to a verso) and show a "Custom" badge. "Reset to template" drops every frame, style and box; photos in boxes go back to the tray. |
| Boxes | Text boxes: id `text-<uuid>`, `role: 'text'`, styled with `{ font: display \| body, sizePt, align, italic }` in the theme's faces and ink (paper over a cover photo). Photo boxes: id `photo-<uuid>`, `role: 'photo'`; a photo may sit in one slot only, so boxes are not duplicated. Template text slots can be moved, restyled or hidden (empty override) but not deleted. |
| Snapping | Guides: trim, bleed, safety (gutter safety on the spine side), page centre, the cover's spine edges, and every other slot's edges and centre. Snap distance 8 screen px; Shift disables snapping. Rotation snaps to 15° within 3°. |
| Crop | A photo's box and its crop are separate: dragging a box moves it; "Adjust crop" (or `C`) on a selected photo switches the drag to moving the picture inside the fixed box, the panel's slider zooms 1 to 3× and Reset restores the centred cover-fit. `Crop.focalX/Y` keep their CSS `object-position` meaning at every zoom (0 = the image's left/top edge against the box, 1 = right/bottom), so `coverCrop` (sharp, print) and `cropImageStyle` (CSS, editor and book page) draw the same window and zooming never jumps. Print HTML gets `croppedImages` because its images are already the cut. Arrows in crop mode nudge the picture 2% of its box (Shift 10%); Esc leaves crop mode first, the selection second. |
| Constraints | Boxes never shrink under 0.25 in and at least 0.25 in of every box stays inside the bleed box. Everything else (safety band, resolution) is advisory: ppi badges, preflight. Photos keep their aspect while resizing unless Alt is held. |
| Undo | One history over pages and cover (100 steps). Drags commit on release; nudges and typing within 800 ms coalesce into one step. |
| Keyboard | Tab through slots, Enter selects, arrows nudge 0.1 in (Shift 0.5 in), `C` toggles the crop tool, `]` / `[` stack, Ctrl+D duplicates a text box, Delete removes, T adds a text box, Ctrl+Z / Ctrl+Y, `?` opens the shortcut list. Focus rings on slots, filmstrip and tray. |
| Rendering | `PageView` and `CoverView` draw from `pageSlots` / `effectiveSlots`, so the editor, the PNG previews and the PDFs are the same markup. Rotation is a CSS transform of the whole box; stacking is `z-index` from `frame.z` (slot order by default). |
